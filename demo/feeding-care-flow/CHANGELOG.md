# Changelog

## 0.3.22 - 2026-08-24

- 删除 `Start Pumping` 后重复的穿戴提示页，点击后直接自动进入泌乳启动和佩戴检测。
- 开始前检查从三步缩减为两步，佩戴通过后直接开始吸乳，舒适档位不再是必经流程。
- 院端和居家控制页补齐模式切换和预设档位交互；只有选中 `Lactation` 时才在档位旁显示 `Best level test` 入口。
- 最佳档位测试改为可选分支，确认结果后回到控制页，并将档位带入后续吸乳页。

## 0.3.21 - 2026-08-21

- 按新版参考图重做居家模式列表：恢复深灰状态栏、圆角白色内容层、`Manual / Programs` 分组和两张完整节奏卡。
- Manual 三种模式统一接入底部 `Rhythm` 韵律弹窗，支持 Gentle、Balanced、Intense 三档韵律选择。
- 韵律弹窗支持关闭、返回、切换和应用，应用结果会回填到居家吸乳控制页。
- 新增韵律弹窗左侧导航页并保持院端 Demo 不变。

## 0.3.20 - 2026-08-21

- 在居家吸乳控制页的 `Switch` 入口后新增完整模式管理分支。
- 新增模式列表、新模式命名、分段总览、参数编辑、完整预览和模式说明 6 个可交互页面。
- 支持两段模式的类型、档位、频率、灯效、开关和试听交互，并将保存结果带回吸乳控制页。
- 新页面全部加入左侧目录和历史返回栈，保持院端 Demo 流程不变。

## 0.3.19 - 2026-08-21

- 为院端和居家端所有可见返回按钮补齐交互热区。
- 返回操作优先回到实际访问的上一个页面，无页面历史时按 Demo 流程顺序回退。
- 返回绑定中、连接中和记录成功等自动跳转页时暂停自动前进，避免刚返回就再次跳走。
- 返回页面时同步恢复绑定、教学、吸乳和记录状态。
- 院端与居家端状态均按版本隔离，避免旧版本标签页覆盖当前 Demo 的返回结果。

## 0.3.18 - 2026-08-21

- 动态替换吸乳中截图内写死的 `Level 1` 和 `1 / 12`，保证上下两处数值一致。
- 吸乳中的 `− / +` 支持在 1–12 档之间继续调节。
