# Changelog

## 0.3.1 - 2026-08-19

- 院端和居家端改为完全独立运行，各自使用单独的本地状态。
- 居家端取消院端绑定前置条件，可直接完成全部流程。
- 院端完成绑定后不再跳转或修改居家端进度。
- 统一入口移除跨端进度展示。

## 0.3.0 - 2026-08-19

- 按 Figma `755:11403`「院端使用流程」重做双端原型，不再使用上一版自拟业务界面。
- 院端串联设备空态、手动添加、发现/扫描、验证码、绑定中和绑定成功。
- 居家端串联设备教学、控制、吸乳中、吸乳记录、成功反馈和数据页。
- 使用 Figma 原始截图作为视觉层，并添加可等比缩放的无障碍交互热区。
- 保留三个访问入口和同源 `localStorage` 跨端同步。

## 0.2.0 - 2026-08-19

- 增加院端 `hospital.html` 与居家端 `home.html` 两个独立访问入口。

- 独立入口继续共享业务状态，可在两个浏览器标签之间演示跨端同步。

## 0.1.0 - 2026-08-19

- 建立院端与居家端双端可交互原型。
